# Human-First ATS Calibration Sandbox

An interactive enablement prototype demonstrating how AI screening tools can be configured to evaluate transferable human capability rather than legacy ATS bias traps (like layoff gaps and rigid tool keywords).

### Architecture & System Design
- **Layer 1 (Deterministic JS Guardrail):** Zero-token regex engine that intercepts toxic configuration rules instantly.
- **Layer 2 (Rubric Judge):** Evaluates semantic nuance and competency-based criteria.
- **Layer 3 (Socratic Coach):** Provides targeted pedagogical hints without handing over the answer.
